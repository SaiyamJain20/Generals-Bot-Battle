### 1. Amin-Debabeche my_bot (VERIFIED by reading source)
- Entry: `competition/agents/my_bot/agent.py` class `Agent(player_id, H, W)`, method `act(obs)` -> `(pass,row,col,dir,split)` tuple, `reset()`. Greedy argmax over masked logits; per-game memory is instance state (create ONE Agent per game, `reset()` or new instance each game).
- `obs` is a dataclass from `main.py`: fields `H, W, turn, my_land, my_army, opp_land, opp_army, type_grid, owner_grid, army_grid` (nested lists [r][c], same codes as ours: type 0 fog/1 plain/2 mtn/3 castle/4 general/5 struct-in-fog; owner 1 me/2 opp). Our dict maps 1:1: `types=obs["type"]`, `owner=obs["owner"]`, `army=obs["army"]`, `height/width`, `my_land...`. Wrapper = `types.SimpleNamespace(H=..,W=..,type_grid=..,owner_grid=..,army_grid=..,...)`.
- Imports `numpy_infer` (sibling file) -> add that dir to sys.path. Needs only numpy. Returns padded-canvas 21x21 coords; agent already passes if r>=H or c>=W. It returns kind 1 = pass, 0 = move, 2 = build (`numpy_infer.decode_action_index`).
- Strength evidence: relh's own docs (`relh_generals-bots/docs/agent-development/external-comparison.md`) pit Sentinel v2 against Amin `my_bot_main8_iter160`: Sentinel 12W-14L-6D over 32 games, i.e. roughly even; this opponent makes ~378 invalid moves per 32 games (silent passes). Median 12 ms/move. So: moderate strength, castle-aware, fast. Good learned-style sparring partner.
- Caveat: weights in the repo are whatever the author last committed (HEAD); a pinned older checkpoint `my_bot_main8_iter160` exists at commit 34506fe2d684f163ada3a0cc3401d192436bfc37 (UNVERIFIED if weights differ from HEAD).

### 2. relh Sentinel (VERIFIED structure; strength numbers are the author's own claims)
- Protocol adapter: `competition/agents/sentinel_python/main.py` (reads the wire frame, builds `generals.core.observation.Observation` of jnp arrays, calls `agent.act(obs, key)` or, for stateful variants, `agent.step(obs, key, memory)` with `memory = agent.initial_memory((H,W))`). Select variant with env `SENTINEL_VARIANT` (default v2; main.py wires v2..v10; v11..v21 exist as `generals/agents/sentinel_v*_agent.py` but main.py only maps up to v10: UNVERIFIED which is strongest, see `docs/agent-development/v21-results.md`, `results.md`).
- Observation build (copy from main.py): `armies=army, generals=types==4, castles=types==3, mountains=types==2, owned_cells=owner==1, opponent_cells=owner==2, neutral_cells=(owner==0)&visible&(types!=2), fog_cells=types==0, structures_in_fog=types==5, owned_land_count..., timestep=turn`, `allied_*` zeros. Return action `[kind,row,col,dir,split]` via `int(x)` on the jnp result.
- Author's results (docs/agent-development/results.md, 3072 games, competition rules): Sentinel v2 beats engine Random 100%, Expander 97.7%, Hunter/Harvester 96.1% (so it is far above the pinned engine bots, a NEW tier of opponent). Max first response 1.7 s, median 5 ms, RSS 222 MB.
- Needs `jax` + `generals` package (the relh fork, NOT the pinned engine: agent files import `generals.core.observation` and others). Run with PYTHONPATH=vendor/ext/relh_generals-bots. Whether it works with the pinned engine's `Observation` class is UNVERIFIED (class fields may differ); safest is to import the relh package in the bot process only.
- Doctrine doc: `docs/agent-development/playing-doctrine.md`.

### Concrete wrapping notes for the top 5 (observation dict -> their input)
Our obs dict: turn, height, width, player_id, my_land, my_army, opp_land, opp_army, type, owner, army (nested lists [r][c]). All five already use the SAME codes (type 0..5, owner 1/2), so conversion is renaming only.
1. Amin `my_bot`: `sys.path.insert(0, ".../vendor/ext/Amin-Debabeche_generals-bots/competition/agents/my_bot")`; `import agent`; per game `a = agent.Agent(player_id, H, W)`; call `a.act(SimpleNamespace(H=H, W=W, turn=t, my_land=.., my_army=.., opp_land=.., opp_army=.., type_grid=obs["type"], owner_grid=obs["owner"], army_grid=obs["army"]))`; returns `(kind,row,col,dir,split)` (kind 1 pass, 0 move, 2 build) -> `list(...)`. Create a fresh Agent when `turn == 0`. Weights load at import (module-level), so import once.
2. blake-ar conv_1313: load `competition/agents/conv_1313/bot.py` via `importlib.util.spec_from_file_location` (module name clash: do not name it `bot`); `Conv1313Agent(H, W)` per game; `.act(SimpleNamespace(height=H, width=W, turn=t, my_land=.., my_army=.., opponent_land=obs["opp_land"], opponent_army=obs["opp_army"], types=obs["type"], owners=obs["owner"], armies=obs["army"]))`. Run its `warmup()` once at first call. Set `JAX_PLATFORMS=cpu`, `XLA_FLAGS=--xla_cpu_multi_thread_eigen=false` and limit threads; keep one process per game to bound RAM. Weights 25 MB bf16.
3. relh Sentinel: put `vendor/ext/relh_generals-bots` on sys.path (its `generals` package shadows the pinned engine's, so run it as a SUBPROCESS via `competition/agents/sentinel_python/run.sh`/`main.py`, which already speaks the stdio protocol; env `SENTINEL_MODE=competition`, `SENTINEL_VARIANT=v2`). This avoids package clashes and is the recommended route; `arena/subproc.py` (untracked, in this repo) looks like the helper for that.
4. Juraj C++: `bash build.sh` in `vendor/ext/juraj/juraj_v35`, then run `./run.sh` as a stdio subprocess (same wrapper as #3).
5. hv-nguyeen: `bot.policy.controller.Controller(player_id, h, w, cfg)`, `.act(obs, deadline)` with `obs` of `bot.obs.Obs` (read `bot/protocol.py read_frame` and `bot/obs.py` to build it from our lists); or run `bot/main.py` as stdio subprocess (`bot/run.sh`), the simplest option. Needs numpy only.

Most robust universal approach for all five: run each as a stdio subprocess with its own `run.sh`/`main.py` (all speak the official wire format) and write ONE generic `bots/opp/ext_stdio.py` adapter that formats our dict into the handshake/frames and reads one line back. Costs a pipe round-trip per move (fine vs 150 ms) and isolates RAM and package clashes.
